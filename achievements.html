過去の大会実績

DNA Vertex Switcher

YOKABIO 2023

Web siteはこちら →

DNAオリガミを用いて、外部からのDNAシグナルに応じて形状を切り替えるDNAナノ構造体を研究しました。菱形十二面体・六面体・八面体の3種類の形状を切り替えることで、将来的には密度を変化させられる新しい材料への応用を目指しました。

本プロジェクトでは、参加チームの上位25%以上に贈られる「Gold Project Award」と、分子ロボティクスに関する特別賞「Molecular Robotics Award」を受賞しました。さらに、「Best Website Award」では2位を獲得しました。

DNA-Clock

YOKABIO 2025

Web siteはこちら →

生物の概日時計に着想を得て、周期的に反応するDNAベースの反応システム「DNA発振」を研究しました。テンプレートDNAを化学的に修飾することで発振周期を制御し、環境の変化に対してより安定したシステムの実現を目指しました。

本プロジェクトでは、「Computational Biomolecular Design Award」、「Gold Project Award」をはじめ、「Best Website Award」2位、「Best Video Award」3位を受賞しました。さらに、世界大会では総合3位にあたる「2nd Runner Up」を獲得しました。
